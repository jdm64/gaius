// FROM SOURCES clone · build · run
01

Clone

$ git clone \
  https://github.com/jdm64/gaius.git

Requires Rust 2024 edition or later.

02

Build

$ cd gaius/cli
$ cargo build --release

One static binary. No runtime, no daemon.

03

Run

$ ./target/release/gaius

First launch walks you through provider & model setup.

Config lives at ~/.config/gaius/config.toml — plain TOML, human-readable, yours to edit. Prefer pipes? gaius --prompt "hello" runs headless and exits.

01

Features

F/01◈

Multi-provider

OpenAI, Anthropic, OpenRouter and more through the genai abstraction layer. Swap models mid-session with /models.

F/02▲

Rust native

Ratatui TUI on tokio. Single binary, instant startup, minimal memory footprint — the Pi-agent experience without the runtime bloat.

F/03◉

Zero telemetry

No analytics, no tracking, no phone-home. Config and sessions live on your disk and nowhere else.

F/04▤

Sessions

Save, load, rename and delete conversations. History persisted locally in MessagePack; resume any session by id with --session.

F/05✦

Agents & skills

Define custom agents in plain TOML files with their own prompts. Invoke skills on demand. Compose behavior, don't hardcode it.

F/06⌗

Full visibility

Markdown rendering, live diffs, thinking traces and per-message token accounting — toggleable with commands.

02

Doctrine

The default system prompt is just the tool descriptions. Nothing more. The harness trusts the model

Minimal

Simple and understandable is the guiding force in every design decision. No ceremony, no magic.

Transparent

Functionally transparent by construction. What you see is what you get — prompts, tools, tokens, all of it.

Yours

No telemetry, no tracking, no accounts. Your providers, your keys, your sessions, your machine.
